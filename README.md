# 🚀 End-to-End ML Pipeline for Churn Prediction

## 🎯 Project Overview
Production-grade machine learning pipeline for customer churn prediction demonstrating ML Engineering best practices.

## 🔥 Features (Coming Soon)
- Data ingestion and validation pipeline
- Feature engineering with Feast feature store
- Model training with MLflow experiment tracking
- FastAPI REST API for predictions
- Docker containerization
- Apache Airflow orchestration
- Comprehensive testing and documentation

## 🛠️ Tech Stack
- Python 3.9+
- scikit-learn, XGBoost
- MLflow (experiment tracking)
- Feast (feature store)
- FastAPI
- Docker & Docker Compose
- Apache Airflow
- pytest
